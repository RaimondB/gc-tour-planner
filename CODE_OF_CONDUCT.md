# Code of Conduct

This project adopts the **Contributor Covenant v2.1** without modification.

The full text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- A plain-text copy: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

By participating in this project (issues, pull requests, discussions, any communication channel under this repo) you agree to follow it.

## Reporting

Please report concerns to the project owner — see the maintainer contact on the GitHub profile of `RaimondB`. Reports are handled privately. We will not retaliate against good-faith reporters.

## Enforcement

The project owner is responsible for clarifying and enforcing these standards. Consequences for violations follow the Community Impact Guidelines published with Contributor Covenant v2.1.

## Why Contributor Covenant

It is widely adopted, externally maintained, and translated into many languages. Using the canonical version (instead of paraphrasing) keeps everyone working from the same well-known reference.
