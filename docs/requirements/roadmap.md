| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| **M1** | Foundations: monorepo scaffold, docs + ADRs, agent instructions, NestJS+Vite skeletons, docker-compose (postgres+valkey), CI, `TourPlannerStrategy` interface skeleton.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | done                         |
| **M2** | Cache ingest: caches schema + migrations, GPX upload + parser, list endpoint with hard filters, basic map markers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | done                         |
| **M3** | OSM context + radius search: Overpass client + `osm_landuse` cache, `ST_Contains` filter, sidebar UI. Soft-preference weighting deferred to M5; async refresh deferred to M4.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | done — hard filter + overlay |
| **M4** | Routing infra. Split for shipping: **M4-α** ships `routing` module (OSRM client, `route_legs` cache, getLeg + getMatrix). **M4-β.0** restructures docs into per-area subdirectories and adds SDLC + sync enforcement. **M4-β** picks up the deferred BullMQ + Valkey wiring and adds upload-triggered precompute: GPX upload completion enqueues (a) `walking-precompute` (OSRM `/table` for each new cache's top-`k_candidates` haversine neighbours within 3 km + re-runs k-NN for affected existing caches, persists to `route_legs`); (b) `overpass-refresh` (landuse around the new caches' convex hull into `osm_landuse`, with serve-stale on user search). Per-cache freshness tracked in `cache_precompute_state` (see [ADR-0007](../adr/0007-precompute-walking-paths-on-upload.md)); operator panel in the web sidebar + `/admin/queues` (bull-board) with "retrigger stale" controls. OSRM container preprocesses the chosen OSM extract in `infra/osrm/bootstrap.sh`. | done                         |
| **M5** | Tour planning. Split for shipping: **M5-α** ships the backend `GreedyTspPlanner` (DBSCAN cluster discovery, NN+2-opt loop, parking selection, two endpoints `POST /tours/clusters` + `POST /tours/plan`). **M5-β** adds the web UI (cluster picker, sidebar form, tour polyline + parking marker, score breakdown panel) and the landuse-weighted soft preference deferred from M3 — backed by `landuse_profiles` with three seeded system profiles (forest-heavy, urban, balanced) and a `GET /landuse-profiles` lookup. Bonus shipped beyond scope: ADR-0011 OSM parking start mode, post-leg-pick fringe trim (FR-T8), `topNClusters` (FR-T9), viewport-following layers (FR-M10), state persistence (FR-M11), OSRM concurrency + Postgres shm hardening (NFR-9).                                                                                                                                                                                                               | done                         |
| **M6** | Persistence + multi-user. Split for shipping: **M6-α** ships the auth backend — argon2id passwords, session issuance in an httpOnly `SameSite=Lax` cookie + double-submit CSRF, a global auth guard replacing `DevUserMiddleware` (with a gated dev/e2e bypass, never in prod), login rate-limiting, and **Google OAuth** (auth-code flow, account-link-by-email) — endpoints `POST /auth/{register,login,logout}`, `GET /auth/me`, `GET /auth/google[/callback]`. **M6-β** adds the auth frontend: TanStack Router (today's `App.tsx` becomes the protected `/` route), login + register pages, an auth context backed by `GET /auth/me`, cookie + CSRF wiring in `api.ts`, and a 401→login redirect. **M6-γ** adds save/list tours (FR-P1, FR-P2): the `tours` migration (designed but unmigrated, plus a `plan` JSONB column) and `POST/GET/PATCH/DELETE /tours[/:id]`. **M6-δ** adds read-only sharing links (FR-P3): `POST`/`DELETE /tours/:id/share` and the public `GET /shared/:slug` over an opaque slug + cache snapshot. Sessions are Valkey-backed (ADR-0021); sharing-link security is ADR-0022. See [persistence-sharing.md](persistence-sharing.md) and [design/auth-and-sharing.md](../design/auth-and-sharing.md). | pending |
